# 21. Merge Two Sorted Lists

## Problem Statement

You are given the heads of two sorted linked lists, `list1` and `list2`.

Merge the two lists into one sorted list by splicing together the nodes from the original lists. Return the head of the merged linked list.

## Example 1

Input: `list1 = [1, 2, 4]`, `list2 = [1, 3, 4]`  
Output: `[1, 1, 2, 3, 4, 4]`

![Merge two sorted lists](https://assets.leetcode.com/uploads/2020/10/03/merge_ex1.jpg)

## Example 2

Input: `list1 = []`, `list2 = []`  
Output: `[]`

## Example 3

Input: `list1 = []`, `list2 = [0]`  
Output: `[0]`

## Constraints

- The total number of nodes in both lists is in the range `[0, 50]`.
- `-100 <= Node.val <= 100`
- Both lists are sorted in non-decreasing order.

## Approach 1: Recursive

Use recursion to decide which node should be first in the merged list.

At each step:

1. If either list is empty, return the other list.
2. Compare the values at the heads of the two lists.
3. Keep the smaller node as the current head.
4. Recursively merge the rest of that list with the other list.

The recursive call reuses the existing nodes and links them together in sorted order.

### Java Solution

```java
class Solution {
	public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
		if (list1 == null) {
			return list2;
		}

		if (list2 == null) {
			return list1;
		}

		if (list1.val <= list2.val) {
			list1.next = mergeTwoLists(list1.next, list2);
			return list1;
		}

		list2.next = mergeTwoLists(list1, list2.next);
		return list2;
	}
}
```

## Approach 2: Iterative

Use a dummy node and a pointer named `current` to build the merged list without recursion.

At each step, attach the smaller head node to `current` and advance that list. When one list is empty, attach the remaining part of the other list.

### Java Solution

```java
class Solution {
	public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
		ListNode dummy = new ListNode(0);
		ListNode current = dummy;

		while (list1 != null && list2 != null) {
			if (list1.val <= list2.val) {
				current.next = list1;
				list1 = list1.next;
			} else {
				current.next = list2;
				list2 = list2.next;
			}

			current = current.next;
		}

		current.next = list1 != null ? list1 : list2;
		return dummy.next;
	}
}
```

## Complexity

- Both approaches run in `O(n + m)` time, where `n` and `m` are the lengths of the two lists.
- Recursive approach: `O(n + m)` space for the call stack in the worst case.
- Iterative approach: `O(1)` auxiliary space.

## Why This Works

At every step, the smallest remaining node must be the smaller head of the two lists. Both approaches attach that node next and continue with the remaining nodes. When one list becomes empty, the other list is already sorted, so it can be attached or returned directly.
