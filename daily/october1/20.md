# 20. Valid Parentheses

## Problem Statement

Given a string `s` containing just the characters `'('`, `')'`, `'{'`, `'}'`, `'['` and `']'`, determine if the input string is valid.

An input string is valid if:

1. Open brackets must be closed by the same type of brackets.
2. Open brackets must be closed in the correct order.
3. Every close bracket has a corresponding open bracket of the same type.

## Example 1

Input: `s = "()"`  
Output: `true`

## Example 2

Input: `s = "()[]{}"`  
Output: `true`

## Example 3

Input: `s = "(]"`  
Output: `false`

## Example 4

Input: `s = "([])"`  
Output: `true`

## Example 5

Input: `s = "([)]"`  
Output: `false`

## Constraints

- `1 <= s.length <= 10^4`
- `s` consists of parentheses only `'()[]{}'`.

## Key Observation

The most recently opened bracket must be the first one closed. That "last in, first out" order is exactly what a **stack** gives us.

A useful trick: when we see an opening bracket, push the **closing** bracket we expect. Then on a closing bracket we only need to check that it equals the top of the stack.

## Approach

1. Scan `s` from left to right.
2. On `'('`, `'['`, or `'{'`, push the matching closing bracket.
3. On a closing bracket, if the stack is empty or its top does not match, return `false`. Otherwise pop.
4. At the end, the string is valid only if the stack is empty.

## Java Solution

```java
class Solution {
    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();

        for (char c : s.toCharArray()) {
            if (c == '(') {
                stack.push(')');
            } else if (c == '[') {
                stack.push(']');
            } else if (c == '{') {
                stack.push('}');
            } else if (stack.isEmpty() || stack.pop() != c) {
                return false;
            }
        }

        return stack.isEmpty();
    }
}
```

## Why This Works

The stack always holds the closing brackets still owed, in the order they must appear. A closing bracket is legal only if it is the one owed most recently. If any closing bracket does not match, or some brackets are still owed at the end, the string is invalid.

## Complexity

- Time: `O(n)`
- Space: `O(n)`
