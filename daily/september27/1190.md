# 1190. Reverse Substrings Between Each Pair of Parentheses

## Problem Statement

You are given a string `s` that consists of lowercase English letters and brackets.

Reverse the strings in each pair of matching parentheses, starting from the innermost one.

Your result should not contain any brackets.

## Example 1

Input: `s = "(abcd)"`  
Output: `"dcba"`

## Example 2

Input: `s = "(u(love)i)"`  
Output: `"iloveu"`

Explanation: The substring `"love"` is reversed first, then the whole string is reversed.

## Example 3

Input: `s = "(ed(et(oc))el)"`  
Output: `"leetcode"`

Explanation: First reverse `"oc"`, then `"etco"`, and finally the whole string.

## Constraints

- `1 <= s.length <= 2000`
- `s` only contains lowercase English characters and parentheses.
- All parentheses are balanced.

## Key Observation

The straightforward approach is a stack of `StringBuilder`s: on `')'`, reverse the current builder and append it to the one below. That is `O(n^2)` in the worst case because inner text gets reversed again at every level.

A better idea is to **not physically reverse anything**. Reversing a bracketed section is the same as reading it in the opposite direction.

So we walk through the string, and whenever we hit a bracket we:

1. Jump to its matching bracket.
2. Flip the reading direction.

This is often called the "wormhole" trick.

## Approach

1. Use a stack to precompute `pair[i]`, the index of the matching bracket for every bracket.
2. Start at index `0` moving right (`direction = 1`).
3. If the current character is a letter, append it.
4. If it is a bracket, teleport to `pair[i]` and flip `direction`.
5. Move one step in the current direction and repeat until we leave the string.

## Java Solution

```java
class Solution {
    public String reverseParentheses(String s) {
        int n = s.length();
        int[] pair = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();

        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);
            } else if (s.charAt(i) == ')') {
                int open = stack.pop();
                pair[i] = open;
                pair[open] = i;
            }
        }

        StringBuilder result = new StringBuilder();

        for (int i = 0, direction = 1; i < n; i += direction) {
            char c = s.charAt(i);

            if (c == '(' || c == ')') {
                i = pair[i];
                direction = -direction;
            } else {
                result.append(c);
            }
        }

        return result.toString();
    }
}
```

## Why This Works

Trace `"(abcd)"`:

```text
i=0 '('  -> jump to 5, direction = -1
i=4 'd', i=3 'c', i=2 'b', i=1 'a'
i=0 '('  -> jump to 5, direction = +1
i=6      -> stop
result = "dcba"
```

A character inside `k` nested pairs is read after `k` direction flips. An odd number of flips means it is read in reverse, an even number means forwards, which matches applying the reversals from the innermost pair outward.

Each bracket is visited exactly twice (once from each side) and each letter exactly once.

## Complexity

- Time: `O(n)`
- Space: `O(n)`
