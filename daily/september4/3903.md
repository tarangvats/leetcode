# 3903. Find the Smallest Stable Index

## Problem Statement

You are given an integer array `nums` of length `n` and an integer `k`.

For each index `i`, define its instability score as:

`max(nums[0..i]) - min(nums[i..n - 1])`

An index `i` is stable if its instability score is less than or equal to `k`. Return the smallest stable index. If no stable index exists, return `-1`.

## Example 1

Input: `nums = [5, 0, 1, 4]`, `k = 3`  
Output: `3`

Explanation:

- Index `0`: `max([5]) - min([5, 0, 1, 4]) = 5 - 0 = 5`
- Index `1`: `max([5, 0]) - min([0, 1, 4]) = 5 - 0 = 5`
- Index `2`: `max([5, 0, 1]) - min([1, 4]) = 5 - 1 = 4`
- Index `3`: `max([5, 0, 1, 4]) - min([4]) = 5 - 4 = 1`

Index `3` is the first index whose score is at most `3`.

## Example 2

Input: `nums = [3, 2, 1]`, `k = 1`  
Output: `-1`

Explanation: Every index has instability score `2`, so no index is stable.

## Example 3

Input: `nums = [0]`, `k = 0`  
Output: `0`

Explanation: The only index has score `0 - 0 = 0`, which is stable.

## Constraints

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 10^9`
- `0 <= k <= 10^9`

## Key Idea

For every index `i`, we need two values:

- The maximum value from the beginning of the array through `i`.
- The minimum value from `i` through the end of the array.

Precompute these values in linear time:

1. Build `prefixMax`, where `prefixMax[i]` is `max(nums[0..i])`.
2. Build `suffixMin`, where `suffixMin[i]` is `min(nums[i..n - 1])`.
3. Scan from left to right and return the first index where:

   `prefixMax[i] - suffixMin[i] <= k`

It is important to return the first valid index, not the index with the smallest instability score. The problem asks for the smallest stable index.

## Java Solution

```java
class Solution {
	public int firstStableIndex(int[] nums, int k) {
		int length = nums.length;
		long[] prefixMax = new long[length];
		long[] suffixMin = new long[length];

		prefixMax[0] = nums[0];
		for (int index = 1; index < length; index++) {
			prefixMax[index] = Math.max(prefixMax[index - 1], nums[index]);
		}

		suffixMin[length - 1] = nums[length - 1];
		for (int index = length - 2; index >= 0; index--) {
			suffixMin[index] = Math.min(suffixMin[index + 1], nums[index]);
		}

		for (int index = 0; index < length; index++) {
			long instabilityScore = prefixMax[index] - suffixMin[index];
			if (instabilityScore <= k) {
				return index;
			}
		}

		return -1;
	}
}
```

## Complexity

- Time: `O(n)`
- Space: `O(n)`

## Why This Works

`prefixMax[i]` exactly represents the maximum of the prefix ending at `i`, and `suffixMin[i]` exactly represents the minimum of the suffix beginning at `i`. Their difference is therefore the instability score for index `i`. Scanning indices from left to right guarantees that the first index satisfying the condition is the smallest stable index.
