# 678. Valid Parenthesis String

## Problem Statement

Given a string `s` containing only three types of characters, `'('`, `')'` and `'*'`, return `true` if `s` is valid.

The following rules define a valid string:

- Any left parenthesis `'('` must have a corresponding right parenthesis `')'`.
- Any right parenthesis `')'` must have a corresponding left parenthesis `'('`.
- Left parenthesis `'('` must go before the corresponding right parenthesis `')'`.
- `'*'` can be treated as a single `')'`, a single `'('`, or an empty string `""`.

## Example 1

Input: `s = "()"`  
Output: `true`

## Example 2

Input: `s = "(*)"`  
Output: `true`

## Example 3

Input: `s = "(*))"`  
Output: `true`

## Example 4

Input: `s = "("`  
Output: `false`

## Constraints

- `1 <= s.length <= 100`
- `s[i]` is `'('`, `')'` or `'*'`.

## Key Observation

Without `'*'`, we would track one number: the count of open brackets. With `'*'`, that count is not fixed, because each `'*'` can add `1`, subtract `1`, or add `0`.

Instead of trying every choice, track the **range** of possible open counts:

- `low`: the smallest possible number of open brackets.
- `high`: the largest possible number of open brackets.

Update rules:

| Character | `low` | `high` |
|-----------|-------|--------|
| `'('`     | `+1`  | `+1`   |
| `')'`     | `-1`  | `-1`   |
| `'*'`     | `-1`  | `+1`   |

Two more rules:

- If `high < 0`, even treating every `'*'` as `'('` cannot save us, so return `false`.
- The open count can never truly be negative, so clamp `low` to at least `0`.

At the end, the string is valid if `low == 0`, meaning `0` open brackets is achievable.

## Java Solution

```java
class Solution {
    public boolean checkValidString(String s) {
        int low = 0;
        int high = 0;

        for (char c : s.toCharArray()) {
            if (c == '(') {
                low++;
                high++;
            } else if (c == ')') {
                low--;
                high--;
            } else {
                low--;
                high++;
            }

            if (high < 0) {
                return false;
            }
            low = Math.max(low, 0);
        }

        return low == 0;
    }
}
```

## Why This Works

After each character, every integer between `low` and `high` is an open-bracket count reachable by some choice of the `'*'` characters so far, without the count ever going negative. Each step shifts or widens this range by one, so it never has gaps.

- `high < 0` means every possible assignment already has more `')'` than `'('`, so no assignment can work.
- Clamping `low` at `0` drops the assignments that went negative, because those are invalid.
- At the end we need some assignment with exactly `0` open brackets, which exists if and only if `low == 0`.

## Alternative

A DP over `(index, openCount)`, or two stacks (one for `'('` indices and one for `'*'` indices), also works. The greedy range approach is the simplest and uses constant space.

## Complexity

- Time: `O(n)`
- Space: `O(1)`
