# 1477. Find Two Non-overlapping Sub-arrays Each With Target Sum

## Problem Statement

You are given an array of positive integers `arr` and an integer `target`.

Find two non-overlapping subarrays whose sums are both equal to `target`. Among all valid pairs, return the minimum possible sum of their lengths.

Return `-1` if no such pair exists.

## Example 1

Input: `arr = [3, 2, 2, 4, 3]`, `target = 3`  
Output: `2`

Explanation: The two subarrays `[3]` at the beginning and `[3]` at the end are the only subarrays with sum `3`. Their combined length is `1 + 1 = 2`.

## Example 2

Input: `arr = [7, 3, 4, 7]`, `target = 7`  
Output: `2`

Explanation: The subarrays `[7]`, `[3, 4]`, and `[7]` all have sum `7`. Choosing the first and last `[7]` gives the minimum combined length of `2`.

## Example 3

Input: `arr = [4, 3, 2, 6, 2, 3, 4]`, `target = 6`  
Output: `-1`

Explanation: Only one subarray has sum `6`, so two non-overlapping subarrays cannot be formed.

## Constraints

- `1 <= arr.length <= 10^5`
- `1 <= arr[i] <= 1000`
- `1 <= target <= 10^8`

## Key Idea

Because all values in `arr` are positive, a sliding window can find every subarray whose sum is `target`.

While scanning the array from left to right, maintain:

- `bestBefore[i]`: the shortest target-sum subarray that ends before index `i`.
- A sliding window representing the current subarray.

When the current window has sum `target`:

1. Its length is a possible right subarray.
2. If a compatible subarray exists before it, combine their lengths.
3. Update the answer with the smallest combined length.
4. Update the best previous length before continuing.

The prefix array makes it possible to carry the best subarray found so far to the next index.

## Java Solution

```java
class Solution {
    public int minSumOfLengths(int[] arr, int target) {
        int n = arr.length;
        int[] bestBefore = new int[n];
        int infinity = n + 1;
        int bestLength = infinity;
        int answer = infinity;
        int left = 0;
        int windowSum = 0;

        for (int right = 0; right < n; right++) {
            windowSum += arr[right];

            while (windowSum > target) {
                windowSum -= arr[left++];
            }

            bestBefore[right] = right == 0
                    ? infinity
                    : bestBefore[right - 1];

            if (windowSum == target) {
                int currentLength = right - left + 1;

                if (left > 0 && bestBefore[left - 1] < infinity) {
                    answer = Math.min(
                            answer,
                            currentLength + bestBefore[left - 1]);
                }

                bestLength = Math.min(bestLength, currentLength);
                bestBefore[right] = Math.min(bestBefore[right], bestLength);
            }
        }

        return answer == infinity ? -1 : answer;
    }
}
```

## Complexity

- Time: `O(n)`
- Space: `O(n)`

## Why This Works

The sliding window finds each target-sum subarray in linear time because all array values are positive. For each current subarray, `bestBefore[left - 1]` stores the shortest target-sum subarray that ends before it, so the two subarrays cannot overlap. Checking every target-sum window and combining it with the best compatible previous window produces the minimum total length.
