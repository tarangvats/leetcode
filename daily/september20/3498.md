# 3498. Reverse Degree of a String

## Problem Statement

Given a string `s`, calculate its reverse degree.

For each character in the string:

- its reversed alphabet value is:
  - `'a' = 26`
  - `'b' = 25`
  - ...
  - `'z' = 1`
- multiply this value by the character's position in the string, using 1-based indexing.

Then sum all the products.

Return the final sum.

## Example 1

Input: `s = "abc"`  
Output: `148`

Explanation:

- `'a'` -> 26 * 1 = 26
- `'b'` -> 25 * 2 = 50
- `'c'` -> 24 * 3 = 72

Total = `26 + 50 + 72 = 148`

## Example 2

Input: `s = "zaza"`  
Output: `160`

Explanation:

- `'z'` -> 1 * 1 = 1
- `'a'` -> 26 * 2 = 52
- `'z'` -> 1 * 3 = 3
- `'a'` -> 26 * 4 = 104

Total = `1 + 52 + 3 + 104 = 160`

## Key Idea

The problem is purely arithmetic. For each character at index `i` (1-indexed):

- `value = 27 - (s.charAt(i) - 'a')`
- contribution = `value * i`

Then sum the contributions for every position.

## Java Solution

```java
class Solution {
    public int reverseDegree(String s) {
        int result = 0;

        for (int i = 0; i < s.length(); i++) {
            int index = s.charAt(i) - 'a';
            int reverseValue = 26 - index;
            result += reverseValue * (i + 1);
        }

        return result;
    }
}
```

## Why This Works

For a character `c`:

- `c - 'a'` gives its 0-based alphabet index.
- `26 - (c - 'a')` converts it to reversed alphabet value.
- Multiplying by `(i + 1)` applies the 1-based position.

Summing these values across the whole string yields the reverse degree exactly as required.

## Complexity

- Time: `O(n)`
- Space: `O(1)`
