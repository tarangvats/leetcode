# 1111. Maximum Nesting Depth of Two Valid Parentheses Strings

## Problem Statement

A string is a valid parentheses string (VPS) if and only if it consists of `"("` and `")"` characters only, and:

- It is the empty string, or
- It can be written as `AB`, where `A` and `B` are VPS's, or
- It can be written as `(A)`, where `A` is a VPS.

The nesting depth `depth(S)` of a VPS is defined as:

- `depth("") = 0`
- `depth(A + B) = max(depth(A), depth(B))`
- `depth("(" + A + ")") = 1 + depth(A)`

Given a VPS `seq`, split it into two disjoint subsequences `A` and `B`, such that both `A` and `B` are VPS's and `A.length + B.length = seq.length`. The subsequences do not have to be contiguous.

Choose `A` and `B` so that `max(depth(A), depth(B))` is as small as possible.

Return an array `answer` of length `seq.length` where `answer[i] = 0` if `seq[i]` belongs to `A`, otherwise `answer[i] = 1`. If multiple answers exist, return any of them.

## Example 1

Input: `seq = "(()())"`  
Output: `[0,1,1,1,1,0]`

## Example 2

Input: `seq = "()(())()"`  
Output: `[0,0,0,1,1,0,1,1]`

## Constraints

- `1 <= seq.length <= 10000`

## Key Observation

If `seq` has depth `D`, the best we can hope for is splitting it into two strings of depth about `D / 2` each.

We can always achieve that by assigning brackets **by the parity of their depth**:

- Brackets at odd depths (1, 3, 5, ...) go to one group.
- Brackets at even depths (2, 4, 6, ...) go to the other group.

Each group then only gets every other level of nesting, so its depth is about half of `D`.

## Approach

1. Keep a running `depth`.
2. On `'('`: increment `depth`, then assign `depth % 2`.
3. On `')'`: assign `depth % 2`, then decrement `depth`.

An opening bracket and its matching closing bracket are at the same depth, so they always land in the same group.

## Java Solution

```java
class Solution {
    public int[] maxDepthAfterSplit(String seq) {
        int[] answer = new int[seq.length()];
        int depth = 0;

        for (int i = 0; i < seq.length(); i++) {
            if (seq.charAt(i) == '(') {
                depth++;
                answer[i] = depth % 2;
            } else {
                answer[i] = depth % 2;
                depth--;
            }
        }

        return answer;
    }
}
```

## Why This Works

Matching pairs share the same depth, so they get the same label, which means each group is itself a valid parentheses string.

Inside one group, two nested pairs must come from depths of the same parity, so they are at least two levels apart in the original string. If the original depth is `D`, each group has depth at most `ceil(D / 2)`. That is optimal, because the deepest chain of `D` nested pairs has to be split across two groups, and one of them must get at least `ceil(D / 2)` of those pairs.

For Example 1, this code returns `[1,0,0,0,0,1]`, which is just Example 1's answer with the labels swapped, so it is also accepted.

## Complexity

- Time: `O(n)`
- Space: `O(1)` extra, not counting the output array
