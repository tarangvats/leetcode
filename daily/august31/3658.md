# 3568. Minimum Moves to Clean the Classroom

## Problem Statement

You are given an `m x n` grid `classroom` where each cell can be one of the following:

- `S`: the starting position of the student
- `L`: litter that must be collected
- `R`: a reset area that restores the student's energy to full capacity
- `X`: an obstacle
- `.`: an empty cell

You are also given an integer `energy`, which represents the maximum energy capacity of the student.

The student starts at `S` with full energy.

In one move, the student can move to an adjacent cell (up, down, left, or right). Each move costs `1` unit of energy. If the energy reaches `0`, the student can keep moving only if they are standing on an `R` cell. When the student reaches an `R`, their energy resets back to the maximum value.

Return the minimum number of moves required to collect all litter cells. If it is impossible to collect all the litter, return `-1`.

## Example 1

Input: `classroom = ["S.", "XL"]`, `energy = 2`  
Output: `2`

Explanation:

The student starts at `(0, 0)` with 2 units of energy.
They move from `(0, 0)` to `(0, 1)`, then to `(1, 1)` to collect the litter.

## Example 2

Input: `classroom = ["LS", "RL"]`, `energy = 4`  
Output: `3`

Explanation:

The student collects one litter, reaches a reset tile, and then collects the second litter.

## Example 3

Input: `classroom = ["L.S", "RXL"]`, `energy = 3`  
Output: `-1`

Explanation:

No valid path exists that collects all the litter.

## Constraints

- `1 <= m == classroom.length <= 20`
- `1 <= n == classroom[i].length <= 20`
- `classroom[i][j]` is one of `'S'`, `'L'`, `'R'`, `'X'`, or `'.'`
- `1 <= energy <= 50`
- There is exactly one `S` in the grid.
- There are at most `10` litter cells.

## Key Idea

This is a shortest-path problem with state tracking.

We do not just care about the current cell; we also care about:

- current remaining energy
- which litter cells have already been collected
- the number of moves taken so far

That means the same grid position can represent different states depending on energy left and collected litter. To handle this correctly, we use BFS over a state space.

### Step-by-step breakdown of the solution

1. Find the start cell `S` and all litter cells `L`.
2. Map each litter cell to a bit in a mask.
   - If there are `k` litter cells, a mask can represent all subsets of them.
   - Example: bit `0` = first litter collected, bit `1` = second litter collected, and so on.
3. Start BFS from `S` with:
   - position `(r, c)`
   - full energy
   - empty mask `0`
   - distance `0`
4. At each step, try all 4 directions.
   - Skip cells outside the grid.
   - Skip obstacles `X`.
   - Skip moves that would make energy negative.
5. If the next cell is an `R`, reset the energy back to maximum.
6. If the next cell is an `L`, update the bitmask by turning on that litter’s bit.
7. Mark the new state as visited.
8. Stop as soon as the mask equals all bits set to `1`, meaning all litter is collected.
9. If BFS finishes without reaching that state, return `-1`.

### Step-by-step breakdown

1. Scan the whole grid
   - Find the start cell `S`.
   - Collect every `L` position into a list.
   - This gives us all litter locations that need to be cleaned.

2. Assign each litter a bit position
   - If there are `k` litter cells, we create a bitmask of length `k`.
   - Each bit represents whether a specific litter has been collected.
   - Example: bit 0 means first litter is collected, bit 1 means second litter, and so on.

3. Build the initial state
   - Start from `S` with full energy.
   - The initial collected mask is `0` because no litter has been picked up yet.
   - We enqueue this state into a queue and mark it visited.

4. Use BFS to explore moves
   - We try all four directions: up, down, left, and right.
   - If the neighbor is out of bounds or is an obstacle `X`, we skip it.
   - If the move would make energy go below `0`, we also skip it.

5. Handle energy reset logic
   - Each move reduces energy by `1`.
   - If the student lands on an `R` cell, the energy resets to the maximum allowed energy.
   - This is why the state stores the current energy value.

6. Update the collected-litter mask
   - If the next cell is a litter cell `L`, then we mark that litter’s bit as collected.
   - That means the state changes from one mask to another mask.

7. Stop when all litter is collected
   - The target mask is all bits set to `1`.
   - If the current state mask equals the target mask, we have cleaned every litter.
   - At that moment, we return the current number of steps.

8. If no valid state reaches the goal
   - Once the BFS queue is exhausted, no valid route exists.
   - We return `-1`.

### Why BFS is used

BFS guarantees the shortest number of moves because every edge costs one step and all states at the same depth are processed before deeper ones. In this problem, the queue explores states by increasing distance, which matches the requirement to find the minimum moves.

### Why the state includes energy and mask

If we only tracked position, the algorithm would fail because:

- the same cell might be reached with different remaining energy
- the same cell might be reached after collecting different litter combinations

Those are different situations and may lead to different future possibilities. So the state must include both energy and collected-litter state.

### Complexity

- Time: `O(m * n * energy * 2^L)` in the worst case
- Space: similar, because we store visited states for each position, energy value, and mask

Here, `L` is the number of litter cells, and it is small due to the problem constraint.


### Why this works

BFS explores states in increasing number of moves, so the first time we reach the goal mask, we have found the minimum number of moves.

The key trick is the bitmask: it helps us remember which litter has already been cleaned, which is essential because the answer depends on both location and progress.

### Why energy and mask must be part of the state

A cell can be reached in different situations:

- with different remaining energy
- after collecting different litter combinations

Those are different states, and the future moves depend on them. So each BFS state is basically:

`(row, col, energyLeft, collectedMask)`

### Complexity

Let `L` be the number of litter cells.

- Time complexity: `O(m * n * energy * 2^L)`
- Space complexity: `O(m * n * energy * 2^L)`

This is manageable because the problem guarantees `L <= 10`.
