# 32. Longest Valid Parentheses

## Problem Statement

Given a string containing just the characters `'('` and `')'`, return the length of the longest valid (well-formed) parentheses substring.

## Example 1

Input: `s = "(()"`  
Output: `2`

Explanation: The longest valid substring is `"()"`.

## Example 2

Input: `s = ")()())"`  
Output: `4`

Explanation: The longest valid substring is `"()()"`.

## Example 3

Input: `s = ""`  
Output: `0`

## Constraints

- `0 <= s.length <= 3 * 10^4`
- `s[i]` is `'('` or `')'`.

## Key Observation

Store **indices** on the stack rather than characters.

The stack holds the indices of unmatched `'('`, and at the bottom it keeps one extra index: the position just before the current valid run starts. We call this the **base**.

- When a `')'` matches something, the current valid run ends at `i` and starts right after whatever index is now on top of the stack. Its length is `i - stack.peek()`.
- When a `')'` has nothing to match, it breaks every run. It becomes the new base.

We start by pushing `-1` as the base, so a run starting at index `0` is measured correctly.

## Approach

1. Push `-1` onto the stack.
2. For each index `i`:
   - If `s[i] == '('`, push `i`.
   - Otherwise pop once.
     - If the stack is now empty, this `')'` was unmatched. Push `i` as the new base.
     - Otherwise update `best = max(best, i - stack.peek())`.
3. Return `best`.

## Java Solution

```java
class Solution {
    public int longestValidParentheses(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(-1);
        int best = 0;

        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);
            } else {
                stack.pop();

                if (stack.isEmpty()) {
                    stack.push(i);
                } else {
                    best = Math.max(best, i - stack.peek());
                }
            }
        }

        return best;
    }
}
```

## Dry Run

For `s = ")()())"`:

```text
start          stack = [-1]
i=0 ')'  pop -> empty, push 0       stack = [0]
i=1 '('  push 1                     stack = [0, 1]
i=2 ')'  pop -> top 0, len = 2      best = 2
i=3 '('  push 3                     stack = [0, 3]
i=4 ')'  pop -> top 0, len = 4      best = 4
i=5 ')'  pop -> empty, push 5       stack = [5]
answer = 4
```

## Why This Works

After processing index `i`, the top of the stack is the last index that is *not* part of a valid substring ending at `i`. That is either an unmatched `'('` or the most recent unmatched `')'` (the base). So `i - stack.peek()` is exactly the length of the longest valid substring ending at `i`, and taking the maximum over all `i` gives the answer.

## Alternative: O(1) Space

Scan left to right counting `open` and `close`. When they are equal, record `2 * close`. When `close > open`, reset both to `0`. Then do the same scan right to left, with the reset rule flipped to `open > close`. The two passes together catch every case, including strings like `"(()"` that a single pass misses.

## Complexity

- Time: `O(n)`
- Space: `O(n)` for the stack (or `O(1)` with the two-pass approach)
