# 5. Longest Palindromic Substring

## Problem Statement

Given a string `s`, return the longest palindromic substring in `s`.

A palindrome is a string that reads the same forward and backward. If more than one longest palindrome exists, return any one of them.

## Example 1

Input: `s = "babad"`  
Output: `"bab"`

Explanation: `"aba"` is also a valid answer.

## Example 2

Input: `s = "cbbd"`  
Output: `"bb"`

## Constraints

- `1 <= s.length <= 1000`
- `s` consists only of digits and English letters.

## Key Idea

Every palindrome has a center. The center is either:

- One character for an odd-length palindrome, such as `aba`.
- The gap between two characters for an even-length palindrome, such as `bb`.

For every index, expand outward from both possible centers while the characters match. Track the longest range found and return that substring.

## Java Solution

```java
class Solution {
	public String longestPalindrome(String s) {
		int bestStart = 0;
		int bestLength = 1;

		for (int center = 0; center < s.length(); center++) {
			int oddLength = expandFromCenter(s, center, center);
			int evenLength = expandFromCenter(s, center, center + 1);
			int currentLength = Math.max(oddLength, evenLength);

			if (currentLength > bestLength) {
				bestLength = currentLength;
				bestStart = center - (currentLength - 1) / 2;
			}
		}

		return s.substring(bestStart, bestStart + bestLength);
	}

	private int expandFromCenter(String s, int left, int right) {
		while (left >= 0
				&& right < s.length()
				&& s.charAt(left) == s.charAt(right)) {
			left--;
			right++;
		}

		return right - left - 1;
	}
}
```

## Complexity

- Time: `O(n^2)`, because each of the `n` centers can expand across the string.
- Space: `O(1)`, excluding the returned substring.

## Why This Works

Expanding from each possible center checks every palindrome that can be formed around that center. Since all palindromes have either one character or a gap between two characters as their center, the longest palindrome must be found during one of these expansions.
