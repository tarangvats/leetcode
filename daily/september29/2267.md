# 2267. Check if There Is a Valid Parentheses String Path

## Problem Statement

A parentheses string is a non-empty string consisting only of `'('` and `')'`. It is valid if any of the following is true:

- It is `()`.
- It can be written as `AB` (`A` concatenated with `B`), where `A` and `B` are valid parentheses strings.
- It can be written as `(A)`, where `A` is a valid parentheses string.

You are given an `m x n` matrix of parentheses `grid`. A valid parentheses string path in the grid is a path that:

- Starts at the upper-left cell `(0, 0)`.
- Ends at the bottom-right cell `(m - 1, n - 1)`.
- Only ever moves down or right.
- Forms a valid parentheses string.

Return `true` if such a path exists, otherwise return `false`.

## Example 1

Input:

```text
grid = [["(","(","("],
        [")","(",")"],
        ["(","(",")"],
        ["(","(",")"]]
```

Output: `true`

Explanation: Two possible valid paths form `"()(())"` and `"((()))"`.

## Example 2

Input: `grid = [[")",")"],["(","("]]`  
Output: `false`

Explanation: The two possible paths form `"))("` and `")(("`, neither of which is valid.

## Constraints

- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 100`
- `grid[i][j]` is either `'('` or `')'`.

## Key Observation

A parentheses string is valid exactly when its **balance** (number of `'('` minus number of `')'`):

1. Never goes negative along the way.
2. Ends at `0`.

So the only thing that matters about a partial path is **which cell we are on** and **its current balance**. Two different paths that reach the same cell with the same balance have identical futures.

That gives a state `(row, col, balance)`, and we can do DFS with a `visited` table so that each state is explored only once.

## Pruning

- Every path has length `m + n - 1`. An odd-length string can never be valid.
- The first cell must be `'('` and the last must be `')'`.
- If `balance` is larger than the number of cells left, we can never close all the brackets.

## Approach

1. Apply the quick checks above.
2. DFS from `(0, 0)` with balance `0`.
3. At each cell, update the balance. Stop if it is negative or too large to close.
4. At the bottom-right cell, succeed if the balance is `0`.
5. Mark `(row, col, balance)` as visited so it is never explored twice.
6. Try moving down and right.

## Java Solution

```java
class Solution {
    private char[][] grid;
    private int m;
    private int n;
    private boolean[][][] visited;

    public boolean hasValidPath(char[][] grid) {
        this.grid = grid;
        m = grid.length;
        n = grid[0].length;

        if ((m + n - 1) % 2 == 1 || grid[0][0] == ')' || grid[m - 1][n - 1] == '(') {
            return false;
        }

        visited = new boolean[m][n][(m + n) / 2 + 1];
        return dfs(0, 0, 0);
    }

    private boolean dfs(int row, int col, int balance) {
        balance += grid[row][col] == '(' ? 1 : -1;

        int remaining = (m - 1 - row) + (n - 1 - col);
        if (balance < 0 || balance > remaining) {
            return false;
        }

        if (row == m - 1 && col == n - 1) {
            return balance == 0;
        }

        if (visited[row][col][balance]) {
            return false;
        }
        visited[row][col][balance] = true;

        return (row + 1 < m && dfs(row + 1, col, balance))
            || (col + 1 < n && dfs(row, col + 1, balance));
    }
}
```

## Why This Works

The validity of the final string depends only on the balance sequence, and the future of a path depends only on its current cell and balance. So if a state `(row, col, balance)` has already been explored and did not lead to success, reaching it again by another route cannot succeed either. That is why `visited` can safely return `false`.

The balance can never exceed half the path length, so the third dimension only needs size `(m + n) / 2 + 1`.

## Complexity

- Time: `O(m * n * (m + n))`, since each state is visited at most once.
- Space: `O(m * n * (m + n))` for the `visited` table.
