# 1520. Maximum Number of Non-Overlapping Substrings

## Problem Statement

Given a string `s` of lowercase letters, return the maximum number of non-empty substrings of `s` that satisfy the following conditions:

1. The substrings do not overlap.
2. If a substring contains a character `c`, then it must also contain every occurrence of `c` in `s`.

Return the substrings in any order.

If multiple answers have the same number of substrings, return the one with the minimum total length. It is guaranteed that a unique answer exists for that minimum total length.

## Example 1

Input: `s = "adefaddaccc"`  
Output: `["e", "f", "ccc"]`

Explanation:

The following are valid substrings:

- `"adefaddaccc"`
- `"adefadda"`
- `"ef"`
- `"e"`
- `"f"`
- `"ccc"`

Choosing `"e"`, `"f"`, and `"ccc"` gives 3 substrings, which is optimal.

## Example 2

Input: `s = "abbaccd"`  
Output: `["d", "bb", "cc"]`

Explanation:

The answer has 3 substrings and a minimum total length among all valid 3-substring solutions.

## Key Idea

For every character, the shortest valid substring that contains all of its occurrences is simply:

- `start = first occurrence of the character`
- `end = last occurrence of the character`

So, for each letter `c`, we get a candidate interval `[first[c], last[c]]`.

A greedy strategy works well here:

- Sort these intervals by their ending index.
- Pick an interval only if its start is strictly greater than the end of the last chosen interval.
- This gives the maximum number of non-overlapping substrings.
- Since we always choose the interval ending earliest, this also minimizes the total length when the count is the same.

This works because every valid answer can be thought of as a set of such minimal covering intervals, and selecting the earliest-ending ones leaves the most room for additional disjoint substrings.

## Java Solution

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<String> maxNumOfSubstrings(String s) {
        int n = s.length();
        int[] first = new int[26];
        int[] last = new int[26];
        Arrays.fill(first, -1);
        Arrays.fill(last, -1);

        for (int i = 0; i < n; i++) {
            int idx = s.charAt(i) - 'a';
            if (first[idx] == -1) {
                first[idx] = i;
            }
            last[idx] = i;
        }

        List<int[]> intervals = new ArrayList<>();
        for (int i = 0; i < 26; i++) {
            if (first[i] != -1) {
                intervals.add(new int[]{first[i], last[i]});
            }
        }

        intervals.sort((a, b) -> {
            if (a[1] != b[1]) {
                return Integer.compare(a[1], b[1]);
            }
            return Integer.compare(a[0], b[0]);
        });

        List<String> answer = new ArrayList<>();
        int lastEnd = -1;

        for (int[] interval : intervals) {
            int start = interval[0];
            int end = interval[1];

            if (start > lastEnd) {
                answer.add(s.substring(start, end + 1));
                lastEnd = end;
            }
        }

        return answer;
    }
}
```

## Why This Works

For each letter, the shortest valid substring must start at its first occurrence and end at its last occurrence. If we sort those candidate intervals by ending position, then greedily taking the earliest-ending disjoint interval is optimal:

- It leaves the most room for the remaining substrings.
- It maximizes the number of non-overlapping valid substrings.
- If several answers have the same count, choosing the earliest-ending ones produces the smallest total length.

The check `start > lastEnd` ensures the selected substrings do not overlap.

## Complexity

- Time: `O(n + 26 log 26)` which simplifies to `O(n)` for a fixed alphabet size.
- Space: `O(26) + O(k)`, where `k` is the number of distinct characters.
