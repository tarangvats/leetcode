# 1614. Maximum Nesting Depth of the Parentheses

## Problem Statement

Given a valid parentheses string `s`, return the nesting depth of `s`. The nesting depth is the maximum number of nested parentheses.

## Example 1

Input: `s = "(1+(2*3)+((8)/4))+1"`  
Output: `3`

Explanation: Digit `8` is inside 3 nested parentheses.

## Example 2

Input: `s = "(1)+((2))+(((3)))"`  
Output: `3`

Explanation: Digit `3` is inside 3 nested parentheses.

## Example 3

Input: `s = "()(())((()()))"`  
Output: `3`

## Constraints

- `1 <= s.length <= 100`
- `s` consists of digits `0-9` and characters `'+'`, `'-'`, `'*'`, `'/'`, `'('`, and `')'`.
- `s` is guaranteed to be a valid parentheses string.

## Key Observation

We do not need a real stack. Since we only care about how deep we are, a counter of currently open brackets is enough:

- `'('` increases the depth.
- `')'` decreases the depth.

The answer is the largest value the counter ever reaches.

## Approach

1. Keep `depth = 0` and `maxDepth = 0`.
2. For each `'('`, increment `depth` and update `maxDepth`.
3. For each `')'`, decrement `depth`.
4. Ignore every other character.

## Java Solution

```java
class Solution {
    public int maxDepth(String s) {
        int depth = 0;
        int maxDepth = 0;

        for (char c : s.toCharArray()) {
            if (c == '(') {
                depth++;
                maxDepth = Math.max(maxDepth, depth);
            } else if (c == ')') {
                depth--;
            }
        }

        return maxDepth;
    }
}
```

## Why This Works

At any position, `depth` equals the number of `'('` that have been opened but not closed yet, which is exactly the number of brackets surrounding that position. The maximum nesting depth is the maximum of this value over the whole string.

## Complexity

- Time: `O(n)`
- Space: `O(1)`
