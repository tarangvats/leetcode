# 1401. Circle and Rectangle Overlapping

## Problem Statement

You are given a circle with center `(xCenter, yCenter)` and radius `radius`, along with an axis-aligned rectangle with corners `(x1, y1)` and `(x2, y2)`, where `(x1, y1)` is the bottom-left corner and `(x2, y2)` is the top-right corner.

Return `true` if the circle and rectangle overlap at any point; otherwise return `false`.

## Example 1

Input: `radius = 1, xCenter = 0, yCenter = 0, x1 = 1, y1 = -1, x2 = 3, y2 = 1`  
Output: `true`

Explanation: The circle and rectangle share the point `(1, 0)`.

## Example 2

Input: `radius = 1, xCenter = 1, yCenter = 1, x1 = 1, y1 = -3, x2 = 2, y2 = -1`  
Output: `false`

## Example 3

Input: `radius = 1, xCenter = 0, yCenter = 0, x1 = -1, y1 = 0, x2 = 0, y2 = 1`  
Output: `true`

## Key Idea

A circle and an axis-aligned rectangle overlap if there exists at least one point inside both shapes.

The easiest way to check this is:

1. Find the closest point on the rectangle to the circle center.
2. Compute the squared distance from the circle center to that closest point.
3. If that squared distance is less than or equal to `radius * radius`, then the circle intersects the rectangle.

For a rectangle, the closest point to `(xCenter, yCenter)` is computed by clamping the center coordinates to the rectangle bounds:

- `closestX = clamp(xCenter, x1, x2)`
- `closestY = clamp(yCenter, y1, y2)`

Then compare:

- `dx = xCenter - closestX`
- `dy = yCenter - closestY`
- If `dx * dx + dy * dy <= radius * radius`, there is overlap.

This handles the cases where the center is inside the rectangle, outside but close to an edge, or near a corner.

## Java Solution

```java
class Solution {
    public boolean checkOverlap(int radius, int xCenter, int yCenter, int x1, int y1, int x2, int y2) {
        int closestX = clamp(xCenter, x1, x2);
        int closestY = clamp(yCenter, y1, y2);

        int dx = xCenter - closestX;
        int dy = yCenter - closestY;

        return (long) dx * dx + (long) dy * dy <= (long) radius * radius;
    }

    private int clamp(int value, int low, int high) {
        if (value < low) return low;
        if (value > high) return high;
        return value;
    }
}
```

## Why This Works

The closest point on the rectangle to the circle center is the center projected onto the rectangle bounds. If the circle center is inside the rectangle, the closest point is just the center itself and the distance is zero, so overlap is immediate.

If the circle center is outside, the nearest possible point to the circle on the rectangle is still on the rectangle boundary. The circle overlaps the rectangle exactly when this nearest point is within radius distance from the center.

This gives a clean constant-time check without enumerating all points or edges.

## Complexity

- Time: `O(1)`
- Space: `O(1)`
