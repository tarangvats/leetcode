# 22. Generate Parentheses

## Problem Statement

Given `n` pairs of parentheses, write a function to generate all combinations of well-formed parentheses.

## Example 1

Input: `n = 3`  
Output: `["((()))","(()())","(())()","()(())","()()()"]`

## Example 2

Input: `n = 1`  
Output: `["()"]`

## Constraints

- `1 <= n <= 8`

## Key Observation

Instead of generating all `2^(2n)` strings and filtering, build strings one character at a time and only make moves that keep the string possibly valid:

- We may add `'('` if we have used fewer than `n` of them.
- We may add `')'` only if it closes something, i.e. `close < open`.

With these two rules, every string that reaches length `2n` is valid, and no work is wasted on dead ends.

## Backtracking Approach

1. Track `open` and `close`, the counts used so far.
2. If the current string has length `2n`, record it.
3. If `open < n`, append `'('`, recurse, then remove it.
4. If `close < open`, append `')'`, recurse, then remove it.

## Java Solution

```java
class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> result = new ArrayList<>();
        backtrack(new StringBuilder(), 0, 0, n, result);
        return result;
    }

    private void backtrack(StringBuilder current, int open, int close, int n, List<String> result) {
        if (current.length() == 2 * n) {
            result.add(current.toString());
            return;
        }

        if (open < n) {
            current.append('(');
            backtrack(current, open + 1, close, n, result);
            current.deleteCharAt(current.length() - 1);
        }

        if (close < open) {
            current.append(')');
            backtrack(current, open, close + 1, n, result);
            current.deleteCharAt(current.length() - 1);
        }
    }
}
```

## Why This Works

A string is well-formed exactly when every prefix has at least as many `'('` as `')'` and the totals are equal. The rule `close < open` guarantees the prefix condition, and `open < n` together with the length check guarantees `n` of each at the end.

Every valid string can be built by this process, because each of its prefixes satisfies both rules. So the recursion generates every answer exactly once.

## Complexity

The number of results is the `n`th Catalan number, which grows like `4^n / (n * sqrt(n))`.

- Time: `O(4^n / sqrt(n))`, since each result takes `O(n)` to build.
- Space: `O(n)` recursion depth, not counting the output.
