# 1658. Minimum Operations to Reduce X to Zero

## Problem Statement

You are given an integer array `nums` and an integer `x`.

In one operation, you can remove either the leftmost or the rightmost element of `nums` and subtract its value from `x`.

Return the minimum number of operations needed to reduce `x` to exactly `0`. Return `-1` if it is impossible.

## Example 1

Input: `nums = [1, 1, 4, 2, 3]`, `x = 5`  
Output: `2`

Explanation: Remove the last two elements, `2` and `3`.

## Example 2

Input: `nums = [5, 6, 7, 8, 9]`, `x = 4`  
Output: `-1`

Explanation: No combination of removals can reduce `x` to exactly `0`.

## Example 3

Input: `nums = [3, 2, 20, 1, 1, 3]`, `x = 10`  
Output: `5`

Explanation: Remove the last three elements and the first two elements.

## Key Observation

The removed elements always come from the two ends, so the elements that remain form one contiguous subarray.

Let:

```text
 total = sum(nums)
```

If the removed elements sum to `x`, then the remaining subarray must have sum:

```text
 total - x
```

Therefore, instead of minimizing the number of removed elements, we maximize the length of a contiguous subarray whose sum is `total - x`.

If the longest valid subarray has length `longest`, then:

```text
minimum operations = nums.length - longest
```

Because all `nums[i]` values are positive, a sliding window can find this longest subarray in `O(n)` time.

## Sliding Window Approach

1. Compute `target = total - x`.
2. If `target < 0`, return `-1`.
3. If `target == 0`, all elements must be removed, so return `n`.
4. Use two pointers, `left` and `right`, to maintain a window.
5. Expand the window by moving `right`.
6. While the window sum is greater than `target`, move `left` forward.
7. Whenever the window sum equals `target`, update the longest window length.
8. Return `n - longest`.

## Java Solution

```java
class Solution {
    public int minOperations(int[] nums, int x) {
        int total = 0;
        for (int value : nums) {
            total += value;
        }

        int target = total - x;
        if (target < 0) {
            return -1;
        }
        if (target == 0) {
            return nums.length;
        }

        int left = 0;
        int windowSum = 0;
        int longest = -1;

        for (int right = 0; right < nums.length; right++) {
            windowSum += nums[right];

            while (windowSum > target) {
                windowSum -= nums[left++];
            }

            if (windowSum == target) {
                longest = Math.max(longest, right - left + 1);
            }
        }

        return longest == -1 ? -1 : nums.length - longest;
    }
}
```

## Why This Works

Every valid sequence of left and right removals leaves a contiguous middle subarray. If the remaining subarray has sum `total - x`, then the removed elements have sum exactly `x`.

For a remaining subarray of length `length`, the number of removed elements is `n - length`. Therefore, minimizing removals is equivalent to finding the longest subarray with sum `total - x`.

Since all values are positive, the sliding window never needs to move the left pointer backward. Each pointer moves across the array at most once, giving a linear-time solution.

## Complexity

- Time: `O(n)`
- Space: `O(1)`
