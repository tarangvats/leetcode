# 3876. Construct Uniform Parity Array II

## Problem Statement

You are given an array `nums1` of `n` distinct integers. Construct an array `nums2` of the same length such that all elements in `nums2` are either odd or even.

For every index `i`, choose exactly one value:

- `nums2[i] = nums1[i]`
- `nums2[i] = nums1[i] - nums1[j]`, where `j != i` and `nums1[i] - nums1[j] >= 1`

Return `true` if such an array can be constructed; otherwise, return `false`.

## Example 1

Input: `nums1 = [1, 4, 7]`  
Output: `true`

Explanation:

- Keep `1` unchanged.
- Replace `4` with `4 - 1 = 3`.
- Keep `7` unchanged.

The resulting array is `[1, 3, 7]`, whose elements are all odd.

## Example 2

Input: `nums1 = [2, 3]`  
Output: `false`

Explanation: The `2` cannot be changed to an odd value because the only smaller value is unavailable. The `3` cannot be changed to an even value because there is no smaller odd number.

## Example 3

Input: `nums1 = [4, 6]`  
Output: `true`

Explanation: Keep both values unchanged. `[4, 6]` contains only even numbers.

## Constraints

- `1 <= n == nums1.length <= 10^5`
- `1 <= nums1[i] <= 10^9`
- `nums1` contains distinct integers.

## Key Idea

There are two possible target parities.

### All even

If every value is already even, keep every element unchanged. This makes the answer `true`.

If an odd value exists, the smallest odd value cannot be changed to an even value: subtracting a smaller number would require another smaller odd value, and no such value exists.

Therefore, an array containing an odd value can never be transformed into an all-even array.

### All odd

Keep every odd value unchanged. An even value `x` must be changed using a smaller odd value `y`:

`x - y` is odd when `x` is even and `y` is odd.

The smallest odd value is the best possible candidate for every even value. Therefore, all even values can be changed to odd values exactly when the smallest odd value is smaller than the smallest even value.

So the answer is `true` when either:

- There are no odd values, or
- The smallest odd value is smaller than the smallest even value.

## Java Solution

```java
class Solution {
	public boolean uniformArray(int[] nums1) {
		int smallestOdd = Integer.MAX_VALUE;
		int smallestEven = Integer.MAX_VALUE;

		for (int value : nums1) {
			if (value % 2 == 0) {
				smallestEven = Math.min(smallestEven, value);
			} else {
				smallestOdd = Math.min(smallestOdd, value);
			}
		}

		return smallestOdd == Integer.MAX_VALUE
				|| smallestOdd < smallestEven;
	}
}
```

## Complexity

- Time: `O(n)`
- Space: `O(1)`

## Why This Works

Parity after subtraction depends only on the parities of the two values. An even value becomes odd only by subtracting an odd value, and an odd value becomes even only by subtracting an odd value. The smallest odd value is the only critical value: it cannot be transformed itself, and it is the easiest valid subtractor for every even value.
