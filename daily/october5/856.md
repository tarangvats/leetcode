# 856. Score of Parentheses

## Problem Statement

Given a balanced parentheses string `s`, return the score of the string.

The score of a balanced parentheses string is based on the following rules:

- `"()"` has score `1`.
- `AB` has score `A + B`, where `A` and `B` are balanced parentheses strings.
- `(A)` has score `2 * A`, where `A` is a balanced parentheses string.

## Example 1

Input: `s = "()"`  
Output: `1`

## Example 2

Input: `s = "(())"`  
Output: `2`

## Example 3

Input: `s = "()()"`  
Output: `2`

## Constraints

- `2 <= s.length <= 50`
- `s` consists of only `'('` and `')'`.
- `s` is a balanced parentheses string.

## Key Observation

The only thing that actually produces points is a core `"()"`. Everything else just doubles or adds.

A core `"()"` sitting inside `d` outer pairs gets doubled `d` times, so it contributes:

```text
2^d
```

Because of the `A + B` rule, the total score is the sum of these contributions over every core `"()"`.

Example: `"(()(()))"`

```text
( ( ) ( ( ) ) )
   ^      ^
   depth 1   depth 2
score = 2^1 + 2^2 = 6
```

## Approach

1. Track `depth`, the number of currently open brackets.
2. On `'('`, increment `depth`.
3. On `')'`, decrement `depth`. If the previous character was `'('`, this is a core `"()"`, so add `1 << depth`.

## Java Solution

```java
class Solution {
    public int scoreOfParentheses(String s) {
        int score = 0;
        int depth = 0;

        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                depth++;
            } else {
                depth--;
                if (s.charAt(i - 1) == '(') {
                    score += 1 << depth;
                }
            }
        }

        return score;
    }
}
```

## Why This Works

Expand the scoring rules: `(A)` doubles every term inside `A`, and `AB` keeps the terms of both sides. So the final score is a sum with one term per core `"()"`, each multiplied by `2` once for every pair enclosing it. After decrementing on the core's `')'`, `depth` is exactly the number of enclosing pairs.

## Alternative: Stack

Push `0` on every `'('`. On `')'`, pop the inner score `v`, and add `max(2 * v, 1)` to the new top. This follows the rules directly but needs `O(n)` space.

## Complexity

- Time: `O(n)`
- Space: `O(1)`
